# Changelog

All notable changes to Open Golf Tracer. Versions are the GitHub release tags; each release has a
Windows installer (`OpenGolfTracer-Setup-<version>.exe`). The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/). A pull request adds its user-visible
changes under **Unreleased**.

## [Unreleased]

## [0.6.0] - 2026-10-18

### Added
- Settings → About: app version, OS, GPU and inference device, FFmpeg version and the data folder
  (with *Open folder* on this PC), links to the licences, third-party notices and this changelog.
- *Save diagnostics*: a zip for bug reports with the version, PC, `performance.json`, recent log
  lines and job summaries. API keys, ChatGPT tokens and anything shaped like a key are removed.
- Log files: the launcher keeps everything the app prints in `data/logs/app-YYYYMMDD.log` for 7 days
  (20 MB cap per file), with keys and tokens masked; the API's own log lines are masked too.
- Update notice: once a day the API asks GitHub for the latest release and the app shows a small
  banner when there is a newer one. It can be turned off under Settings → About (see `docs/privacy.md`).
- `THIRD_PARTY_NOTICES.txt` in the Windows installer (generated by `scripts/third_party_notices.py`)
  and `models/LICENSE-rf-detr` next to the ball detector.
- Bug report template, `SECURITY.md`, pull request template and this changelog.
- Storage settings: what the projects take, beside the free space; a warning before the disk is full.
- Shot review: *Looks right* button, the shot type can be changed, shots grouped by hole.
- Exports are listed outside the editor; batch export with a zip download; *My videos* shows
  thumbnails, a link to the project and *Open folder*. Projects are grouped under their round.
- *Save mine as a copy* when another tab saved the same project. The save badge says why a save failed.
- YouTube description and chapters work without AI.
- `GEO_LOOKUP` setting to turn off the OpenStreetMap (Overpass) course lookup.

### Changed
- The launcher's and `setup.sh`'s messages are in English. `docs/licensing.md` is in English.
- The API's OpenAPI version comes from the root `package.json`.

### Fixed
- Jobs are no longer marked *canceled* after the PC sleeps, and Windows does not idle-sleep while
  jobs run. Concurrent saves of a project's analysis no longer lose clips.
- The database is backed up before a migration, with a clear message when the data is from a newer version.
- Variable frame rate clips and clips with a non-zero start time get correct shot times; an error in
  one shot no longer fails the whole clip; cancel is faster and 25-50% fewer frames are decoded.
- Export: sound and tracer no longer drift, the video uses the app's language, mixed HDR/SDR clips
  export as SDR, peak memory is much lower, a failed export leaves no half-written file, and the
  reframe zoom matches the preview.
- Editor: undo by id, saves never overwrite another tab's changes, media links refresh after expiry.
- *Make a video for me*: works with OpenAI reasoning models and Ollama's chat API, retries reuse the
  saved plan instead of paying again, and a job waiting for answers resumes after a reload.

### Security
- DNS rebinding: `X-Forwarded-Host` is no longer trusted on its own; `Host` is always checked.
- The stored AI key is dropped when the provider or its address changes; the AI key and ChatGPT
  tokens are encrypted with DPAPI on Windows. Names sent to AI prompts are escaped.
- The installer's Node, FFmpeg, Python and Inno Setup downloads are pinned with SHA-256, Python
  dependencies use hashed lock files, and a release is only built after CI and an installer smoke test pass.

## [0.5.4] - 2026-10-17

### Added
- Optimise measures GPU video decoding (d3d11va, cuda, dxva2, qsv, vaapi) and picks it when it is
  faster and gives the same frames.
- Tracer handles outside the picture are drawn as pins on the edge; *Bring the flight into the
  picture*, *Draw the flight* (three clicks) and a reset that pulls a wild auto flight into view.

### Fixed
- A GPU decoder that fails, or returns too few frames, falls back to the CPU from the first missing
  frame and is skipped until Optimise runs again (`decodeFailed` in `performance.json`).
- Flights that would end far outside the frame are replaced by an in-frame guess.

## [0.5.3] - 2026-10-17

### Added
- Click a shot to jump to it, with the timeline scrolled into view and *Put it back in* for a shot
  that was removed.
- Scorecard panel: par, strokes, putts and to-par per hole, with per-hole corrections used by the
  videos, the scorecard graphic and the AI.
- Putt roll line: the path the ball rolled, drawn on the green (off by default, per putt).

### Fixed
- DirectML crashed with two detector sessions at once; DirectML now uses one session, and Optimise
  tunes for that.
- Faster frame preprocessing (39 → 19 ms per 1080p frame, same output); malformed
  `performance.json` files no longer crash the worker or API.

## [0.5.2] - 2026-10-17

### Added
- Clean cuts: each shot gets a "clean window", and automatic cuts stop before someone walks into
  the picture or the camera moves.
- Editor: ripple editing, trimming by dragging clip edges with a live preview, multi-select and new
  shortcuts; playback no longer re-renders the timeline, and the overlay is drawn in a Web Worker.
- AI: a vision budget of its own, a fact guard against invented scores and distances, highlight tags.

### Changed
- Much less putting by default, with stricter putt detection.
- "Make video for me" is the single main action; the app starts in the browser's language; clearer
  first run, export card and error states.
- AI errors never fail the video: the rule plan is used with a note.

## [0.5.1] - 2026-10-17

### Added
- Performance profiles (Gentle, Balanced, Max) and *Optimise*, a benchmark that saves the fastest
  safe settings for this PC; out-of-memory errors step the profile down.
- AI provider "ChatGPT (your plan)" via Sign in with ChatGPT (preview).

### Changed
- Faster analysis with identical results (detector session pool, overlapped decoding).

## [0.5.0] - 2026-10-16

### Changed
- No code changes since v0.4.0: the release that bumped `package.json` to 0.4.0 (PR #10) was tagged v0.5.0.

## [0.4.0] - 2026-10-16

### Added
- Putts without a tracer, a score per hole and the distance to the next shot.
- Optional vision check: still frames from the green when the putt count is unsure (off by default).
- Shot cards in "Make video for me" questions, robust clip order for a round, and recognising the
  same shot filmed twice.

### Changed
- Faster ingest: one decode for proxy and thumbnails, GPU scaling, two clips at once.

## [0.3.0] - 2026-10-16

### Added
- "Make video for me": the app plans and cuts a YouTube video, highlight or shorts from a
  preference, without AI, and asks when in doubt.
- Optional AI model (Ollama, OpenAI-compatible or Anthropic) for wording, titles and the plan.

### Fixed
- The installed app trusts the Windows certificate store, so cloud AI works behind antivirus that
  intercepts HTTPS.

## [0.2.0] - 2026-10-15

### Changed
- The ball detector runs as ONNX with ONNX Runtime (DirectML on any Windows GPU), so the installer
  has everything in it and downloads nothing.

### Fixed
- The 0.1.0 installer failed with error 448 on newer Windows 11 builds.

## [0.1.0] - 2026-10-15

### Added
- First Windows installer for non-technical users: per-user install, no admin rights, English and
  Danish wizard, `data\` kept across updates.
